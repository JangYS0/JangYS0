### Hi, I'm JangYS 👋

I build zero-upload, browser-memory-only developer utilities at **[NerdKit (global-utils.com)](https://global-utils.com/en)** so teams can inspect production files (`.parquet`, `.har`, PostgreSQL `EXPLAIN ANALYZE`, WebAuthn CBOR, `mcp.json`, `docker-compose.yml`) without uploading sensitive data to remote servers.

#### Open-Source Zero-Dependency MIT Tools
- **[nerdkit-mcp](https://github.com/JangYS0/nerdkit-mcp)** — Local Node.js `stdio` MCP server (`redact_har_secrets`, `analyze_postgres_explain`, `calculate_llm_vram`, `lint_mcp_config`) · [Browser MCP Inspector](https://global-utils.com/en/mcp-inspector)
- **[redos-lint](https://github.com/JangYS0/redos-lint)** — Static CLI linter for catastrophic backtracking (ReDoS) regexes · [Browser Regex Visualizer](https://global-utils.com/en/regex-visualizer)
- **[har-redact](https://github.com/JangYS0/har-redact)** — Strip Bearer tokens, cookies, query secrets, and GraphQL variables from Chrome `.har` exports · [Browser HAR Analyzer](https://global-utils.com/en/har-analyzer)
- **[pg-explain-hotspot](https://github.com/JangYS0/pg-explain-hotspot)** — Flag PostgreSQL `EXPLAIN ANALYZE` row-estimate mismatches and sequential scans · [Browser SQL Explain Visualizer](https://global-utils.com/en/sql-explain-visualizer)
- **[llm-vram-calc](https://github.com/JangYS0/llm-vram-calc)** — Estimate GQA & DeepSeek MLA KV-cache GPU VRAM · [Browser GPU VRAM Calculator](https://global-utils.com/en/gpu-vram-calculator)
